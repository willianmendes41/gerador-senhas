# Gerador de Senhas Aleatórias

Um gerador de senhas aleatórias simples e responsivo, desenvolvido com HTML, CSS e JavaScript puro.

## 🚀 Funcionalidades

- Geração de senhas aleatórias com 14 caracteres
- Caracteres incluídos: números, letras (maiúsculas e minúsculas) e símbolos especiais
- Interface responsiva para desktop, tablets e dispositivos móveis
- Botão para copiar a senha gerada
- Design moderno com tema rosa
- Feedback visual ao copiar a senha

## 🎨 Tecnologias Utilizadas

- **HTML5** - Estrutura da página
- **CSS3** - Estilização e responsividade
- **JavaScript** - Lógica de geração de senhas
- **Font Awesome** - Ícones
- **Google Fonts (Roboto)** - Tipografia

## 📱 Responsividade

O projeto foi desenvolvido para ser totalmente responsivo, com adaptações para:
- Desktop (acima de 768px)
- Tablets (até 768px)
- Smartphones (até 480px)
- Telas pequenas (até 420px)

## 🛠️ Como Usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/gerador-senhas.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd gerador-senhas
   ```

3. Abra o arquivo `index.html` no seu navegador

4. Clique no botão "Gerar" para criar uma nova senha

5. Clique no ícone de copiar para copiar a senha para a área de transferência

## 📁 Estrutura do Projeto

```
gerador-senhas/
├── index.html      # Estrutura HTML principal
├── style.css       # Estilos CSS e responsividade
├── index.js        # Lógica JavaScript
└── README.md       # Documentação do projeto
```

## 🔧 Personalização

Você pode personalizar o projeto editando:

- **Tamanho da senha**: Altere a variável `passwordLength` no arquivo `index.js`
- **Caracteres utilizados**: Modifique a string `chars` no arquivo `index.js`
- **Cores**: Edite as cores no arquivo `style.css`
- **Tamanhos**: Ajuste as media queries no arquivo `style.css`
